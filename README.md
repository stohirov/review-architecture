# review-architecture

An agent skill that reviews a system's architecture and recommends fixes.

- **Codebase mode**: run it inside a repo. It profiles the project, sends parallel lens agents through the code, verifies their findings, and writes a report.
- **Design mode**: describe a planned project. It asks only for what's missing and reviews the design before code exists.

Work in progress.

## Install

```
/plugin install review-architecture --marketplace stohirov/review-architecture
```
